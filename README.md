# Welcome to tn-hyperskill

This organization holds my portfolio of Hyperskill-based Java projects. I’ve focused on writing clean, testable code, automating builds, and documenting the software so it’s easy for anyone to run and review.

Feel free to explore the repositories below:

| Repository                                   | Description                                       | Technologies     |
|----------------------------------------------|---------------------------------------------------|------------------|
| [medium-battleship-solution](https://github.com/tn-hyperskill/medium-battleship-solution)     | A console-based Battleship game, showcasing multi-step project structure and Gradle build integration. | Java, Gradle     |
| [medium-battleship-last](https://github.com/tn-hyperskill/medium-battleship-last)            | Final polished version of the Battleship project, using Maven and additional tests.         | Java, Maven      |
| [challenging-pwd_hacker-solution](https://github.com/tn-hyperskill/challenging-pwd_hacker-solution) | A password brute-force tool (“Password Hacker”) in Java, plus Gradle-based environment.      | Java, Gradle     |
| [challenging-pwd_hacker-last](https://github.com/tn-hyperskill/challenging-pwd_hacker-last)  | Standalone, final iteration of the Password Hacker, complete with tests and static analysis. | Java, Maven      |
| [hard-sorting_tool-solution](https://github.com/tn-hyperskill/hard-sorting_tool-solution)    | A multi-step sorting application with integrated tests and documentation.                   | Java, Gradle     |
| [hard-sorting_tool-last](https://github.com/tn-hyperskill/hard-sorting_tool-last)            | Final build of the sorting tool with Maven, additional analysis, and improved doc.           | Java, Maven      |

**Key Highlights:**

- **Gradle & Maven**: Each project includes a standardized build, so you can clone and build quickly.
- **Testing & Quality**: Some repos feature unit tests, static analysis (SpotBugs, PMD, Checkstyle), and coverage reports.
- **Documentation**: Each “-last” repo has a README explaining how to run the project and, in some cases, deeper design notes.

If you have any questions or want more information, feel free to open an issue or contact me directly.

Thanks for stopping by!
