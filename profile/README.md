## Repo-naming convention
### Prefixes
{`medium`, `hard`, `challenging`, ...} – level of difficultly per Hyperskill platform
**Warning:** the level of difficultly should be inverse. Hyperskill seems to have made mistake. I've put more effort into "easier" projects.
### Root
{`battleship`, `sorting_tool`, `pwd_hacker`, ...} – name of the project. Similar to the one from Hyperskill.
### Suffixes
#### `last`
Final polished version. Last exercise only.
##### Features
* **Standarised maven build**. Should be very easy to use.  
* **Documentation**: Each “-last” repo has a README explaining how to run the project and, in some cases, deeper design notes.  
* **Testing & Quality**: Many repos feature unit tests, static analysis (SpotBugs, PMD, Checkstyle), and coverage reports.  
#### `solution`
Solution compatible with **IntelliJ JetBrains Academy** plugin.
**Warning:** it includes gradle scripts, but you probably **not be able to run/navigate it properly without a IntelliJ + plugin**.
